We continue by creating the jump function, and first of all, we need to import the
TouchableWithoutFeedback element. TouchableWithoutFeedback supports only one
child. If you wish to have several child components, wrap them in a View. Importantly,
TouchableWithoutFeedback works by cloning its child and applying responder props to it. It
is therefore required that any intermediary components pass through those props to the
underlying React Native component.
