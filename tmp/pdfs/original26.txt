Flappy Bird
In todayʼs lesson, we start with Game Development, and as a game to develop, we selected
Flappy Bird, one of the most simple-famous games. First, we need to demonstrate how the
game will work if any of the students donʼt have information about how the game is played
or how it works. For this, we use http://flappybird.io/, which demonstrates us in the best
way. After explaining game logic to the students, we continue to set up a new project which
will be flappy-bird-rn.
Somewhere on the Desktop, we open git bash, and we run the command which is used to
create a project.
expo init flappy-bird-rn --template blank
